📋 What This App Does

database-manager is a simple desktop program for Windows. It lets you merge many files into one master Excel file. This is especially useful if you work with contact lists, product catalogs, or student records.

Think of it like a blender for your spreadsheets – you put in multiple files, and it creates one smooth, clean database. The magic is that the app adds a column to every row showing which file it originally came from. No more confusion about data sources!

✨ Key Features

  • 🔄 Merge Many Formats: Combine Excel (.xlsx), CSV, plain TXT, and vCard (.vcf) files in one go.
  • 📍 Source Tracking: Every row gets an extra column (e.g., "Source File") so you always know where data came from.
  • 🔍 Adaptive Columns: The app automatically adjusts column headers based on your data. It works with contacts, products, students, or any custom schema you want.
  • 📊 Duplicate Highlighting: Quickly spot repeated entries. The app can highlight or flag duplicates for easy cleaning.
  • 🌍 3 Languages: Interface available in Uzbek, Russian, and English.
  • 💻 User-Friendly: No coding needed. A clean graphical interface guides you step by step.

🚀 Getting Started on Windows

Step 1: Download the App

Visit this link to download the application.

⬇️ Go to Download Page

Step 2: Run the Program

After downloading, double-click the file just like any other Windows program. If you see a blue or yellow prompt saying "Windows protected your PC," click on "More info" and then "Run anyway". This is normal for new apps from the internet.

The program window will open. You don't need to install anything else – it works standalone.

Step 3: Load Your Files

  1. Click the "Add Files" button (or drag and drop your files into the window).
  2. Select one or many Excel/CSV/TXT/vCard files from your computer.
  3. Choose the language for the interface: Uzbek, Russian, or English (top corner).
  4. Click the big "Merge" button.

Step 4: Save Your New Database

The app asks where to save the merged Excel (.xlsx) file. Pick a location and name it something like "All_Contacts_2025.xlsx". That's it!

💡 Tip: Before merging, make sure all your CSV/TXT files have the same column order (e.g., Name, Phone, Email). The app will match headers automatically if possible, but consistent columns save you from later formatting chores.

❓ Frequently Asked Questions

Do I need to install Python or anything else?

No. The file is a standalone Windows executable (.exe). It includes everything needed.

Will my data be uploaded to the internet?

No. Everything runs on your computer. Your files never leave your machine.

Can I use empty columns?

Yes. The app handles missing values gracefully lefting empty cells empty or you can fill them later in Excel.

How does duplicate highlighting work?

The app checks rows for duplicate values in the first column (or a key column you select). Duplicates get a distinct color and you can optionally delete duplicates with one click.

Which Excel version is compatible?

The output file is .xlsx format, which works in Excel 2010 and newer, including Office 365, LibreOffice, and Google Sheets.

🖥️ System Requirements

Any modern Windows computer (Windows 8/10/11). At least 2 GB of RAM and about 50 MB of free disk space for the app itself. Works fine on older machines too.
